# レビュー

差分をレビューするときは、次の点を確認する。

- `src/` を変更しているのに `package.json` の `version` が上がっていない。リリース workflow はタグと `version` が一致しないと失敗する
- `.cpm-state.json` に記録していないものを、削除・上書きしている
- トークンの値を、出力・ログ・エラーに含めている(要求 URL とレスポンス本文は、エラー調査のため出力してよい)
- 挙動を変えたのに、テストが更新・追加されていない

指摘は重大度順に、日本語で短く書く。直す箇所は `file_path:line_number` で示す。
